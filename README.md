# Кварта — сайт кофейной мастерской

Сайт небольшой кофейной мастерской на Next.js App Router. Главная страница рассказывает о мастерской, показывает ассортимент и подписку, а форма отправляет заявку в API. Интерфейс ориентирован на desktop; мобильную адаптацию пока не делали.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

SQLite-файл создаётся при первом запросе к API по адресу `data/leads.sqlite`. Путь можно изменить переменной окружения `SQLITE_PATH`. Проверка TypeScript: `npm run typecheck`; сборка: `npm run build`.

Интерфейс собран на Tailwind CSS. Поля заявки проверяются через React Hook Form и Zod; анимации сделаны с Framer Motion.

## API

### `GET /api/health`

Проверяет доступность API и SQLite. При успехе возвращает `200`.

### `POST /api/lead`

Тело запроса — JSON. Обязательные поля: `name`, `phone`, `interest`. Значение `interest`: `subscription`, `single_order` или `question`. Номер можно передавать как `+375291234567`, `80291234567` или девять цифр белорусского номера; он сохраняется в нормализованном формате `+375...`.

```json
{
  "name": "Алексей",
  "phone": "+375 29 123-45-67",
  "interest": "subscription",
  "comment": "Хочу оформить подписку",
  "utm_source": "instagram",
  "utm_medium": "paid",
  "utm_campaign": "october-coffee",
  "utm_content": "story-1",
  "utm_term": "кофе в Минске",
  "gclid": "example-click-id",
  "pageUrl": "https://example.com/?utm_source=instagram"
}
```

`comment`, UTM-поля, `gclid` и `pageUrl` необязательны. `Referer` запроса также сохраняется в поле `referrer`. Успешный ответ — `201` с идентификатором заявки; `400` означает неверный JSON, `415` — неверный Content-Type, `422` — ошибки полей, `409` — повторную заявку с того же номера в течение 10 минут, `500` — ошибку сохранения. Повтор проверяется внутри немедленной транзакции SQLite, поэтому конкурирующие запросы не создают две заявки.

## Запросы для Postman

Создайте запрос `GET http://localhost:3000/api/health` для проверки сервера и базы.

Для успешной заявки используйте `POST http://localhost:3000/api/lead`, заголовки `Content-Type: application/json` и `Referer: https://example.com/coffee?utm_source=instagram`, а в Body → raw → JSON вставьте пример тела выше.

Проверьте ошибки, повторяя тот же POST:

- Укажите `phone: "123"` — ожидается `422` и подсказка по номеру.
- Сразу отправьте исходный запрос ещё раз — ожидается `409 DUPLICATE_LEAD`.
- Отправьте некорректный JSON (например, `{`) — ожидается `400 INVALID_JSON`.

## Работа с базой и хранилище

`lib/database.ts` создаёт и настраивает Sequelize, модель заявки и таблицу; `lib/leads.ts` экспортирует функции `createLead` и `DuplicateLeadError` для работы с заявками. Подключение проверяется и схема синхронизируется при первом запросе. SQLite выбран для локального прототипа: отдельный сервер базы не нужен. Файл базы и WAL-файлы исключены из Git. Для серверлесс-хостинга (например, Vercel) локальная файловая система не гарантирует постоянное хранение между запусками; перед таким деплоем SQLite нужно заменить на постоянную managed-базу или подключить хранилище с постоянным диском.
